# Mini Search Engine

A console-based Java mini search engine that allows users to search through a collection of documents using keywords.

## Features

- Add and store documents
- Search documents using keywords
- Case-insensitive searching
- Multi-word search
- Keyword indexing using HashMap
- HashSet-based document tracking
- Display matching documents
- Simple console-based interface

## Technologies Used

- Java
- ArrayList
- HashMap
- HashSet
- Object-Oriented Programming
